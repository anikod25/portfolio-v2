# Aniket Kodgirwar — Field Notes

A responsive portfolio built with React, TypeScript, Vite, Motion for React, and custom CSS. The tactile field-journal treatment appears in the hero; the rest of the site uses ordinary vertical scrolling and anchor navigation.

## Run locally

```bash
npm install
npm run dev
```

Build and lint:

```bash
npm run build
npm run lint
```

## Sections

- Journal-inspired introduction hero
- Selected projects: AEGIS, KIRA, WILHELM, SecureNite, and ContainerCraft
- Skills and technical interests
- Five-item achievement gallery, followed by separate Leadership and Education panels
- About, including the writing and poetry note
- Desk-inspired contact and verified profile links

The project archive switches between project-specific conceptual diagrams. Selecting an entry opens its case note inline, keeping the document scrollable. Achievement exhibits use original typography and diagrams rather than fabricated photos or certificates. The responsive menu provides direct links to the main sections.
